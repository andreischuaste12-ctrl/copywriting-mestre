# Michel Fortin — fórmula QUEST

**Papel:** autor de uma estrutura de copy (entra como autor de fórmula).
**Contribuição central:** **QUEST**: Qualify → Understand → Educate → Stimulate → Transition.

## Como usar a estrutura
1. **Qualify:** deixar claro para quem é. 2. **Understand:** mostrar que entende o problema. 3. **Educate:** ensinar algo útil. 4. **Stimulate:** despertar interesse na solução. 5. **Transition:** conduzir ao próximo passo.

## Quando invocar
- Conteúdo que educa antes de vender; público com baixa consciência ou comparando soluções.

## Cuidados
- Educar não dispensa prova nem CTA claro.
