# Robert Collier — Start with the Reader's Context

**Associated work:** *The Robert Collier Letter Book* (1931). The editorial lens is to connect the message with the reader's existing concerns and interests.

- Begin with what the reader thinks, feels, or says; use their vocabulary and a recognizable scene before introducing the offer.
- Consult for sales letters, email, and openings for cold or problem-aware audiences.
- If VoC sources exist, select up to three relevant literal quotes; use fewer when fewer are available. Never invent or alter quoted language. Without VoC, label a proposed opening as an editorial hypothesis.
- A recognizable scene is not evidence. The popular quotation about entering the conversation already in a customer's mind has not been verified in an original source; use the idea without quotation marks.
