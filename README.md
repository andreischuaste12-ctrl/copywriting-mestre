# copywriting-mestre
Based on the strategies and writing styles of history’s greatest copywriters, define the most effective communication structure for each audience, considering their pain points, desires, level of awareness, and goals.

## Skill `copywriter-mestre`

Fonte única em `.claude/skills/copywriter-mestre/` (Claude Code). `.agents/skills/copywriter-mestre` é um symlink para a mesma pasta (Codex).

- Diagnóstico com 2–4 perguntas quando faltar contexto; entrega de 3–4 variações (PAS, BAB, quebra de objeção, urgência/ação).
- Modo estudo: Dores Principais, Desejos Ocultos, Objeções e UVP.
- Base teórica: `references/codex-copywriting.md`.

Ativação global (fora deste repo): copie ou aponte a pasta para `~/.claude/skills/` e `~/.agents/skills/`. No Windows, symlinks exigem modo desenvolvedor; sem ele, copie a pasta em vez de linkar.
